# BoShibi Website

เว็บไซต์แนะนำตัวสำหรับ BoShibi — Siberian Husky VTuber

## เปิดดูในเครื่อง
1. แตกไฟล์ ZIP
2. เปิด `index.html` ด้วยเว็บเบราว์เซอร์

## อัปโหลดขึ้น GitHub Pages
1. สร้าง repository ใหม่บน GitHub
2. อัปโหลด `index.html` และโฟลเดอร์ `assets/` เข้า repository
3. เข้า **Settings → Pages**
4. ใน **Build and deployment** เลือก **Deploy from a branch**
5. เลือก branch `main` และ folder `/ (root)` แล้วกด Save
6. รอ GitHub สร้างเว็บไซต์ แล้วเปิด URL ที่แสดงในหน้า Pages

## ก่อนเผยแพร่
- แก้วันและเวลาในส่วน `ตารางไลฟ์ของโบ้` ให้ตรงกับตารางจริง
- เพิ่มภาพ อนิเมชั่นลูป ฟิกเกอร์ของสะสม ราคา และลิงก์สั่งซื้อในส่วนร้านค้าเมื่อพร้อมขาย
- ภาพตัวละครอยู่ใน `assets/boshibi-avatar.png` และใช้ภาพที่เจ้าของอัปโหลดเท่านั้น
- เว็บไซต์นี้เป็นหน้าแนะนำตัวแบบ static ยังไม่มีระบบตะกร้าสินค้า/ชำระเงิน

## ปรับแต่ง
เนื้อหา สี และ layout อยู่ใน `index.html` ทั้งหมด ไม่ต้องติดตั้งโปรแกรมหรือ framework เพิ่ม


## สินค้าภาพดิจิทัลราคา 9 บาท
- รูปสินค้าอยู่ที่ `assets/boshibi-photo-01.png`
- ปุ่มชำระเงินเชื่อมไปที่ `https://ezdn.app/bophutpairueai`
- มีช่องให้ผู้ซื้อเลือกไฟล์สลิปและดูตัวอย่างไฟล์ในหน้าเว็บ
- **สำคัญ:** GitHub Pages เป็น static hosting แบบฟอร์มในตัวอย่างยังไม่ได้ส่งไฟล์สลิปไปหาผู้ขาย ต้องเชื่อม backend หรือบริการรับไฟล์/ฟอร์มที่รองรับ upload ก่อนใช้งานจริง

- ในหน้าร้านค้า ผู้ชมต้องกดหมวด **ภาพ** ก่อน จึงจะแสดงรายการสินค้า และกดสินค้าเพื่อเปิดรายละเอียด/ราคา/ชำระเงิน
